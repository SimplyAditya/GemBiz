# GemBiz Project Context

This document provides an overview of the GemBiz project, a microservices-based application.

## Project Structure

The project consists of six main services:
- **gateway**: The main entry point for all API requests. It's an Apollo Gateway that composes the schemas from the other services.
- **users**: Manages user data and user-related operations.
- **auth**: Handles user authentication and authorization.
- **products**: Manages product data and product-related operations.
- **cart**: Manages shopping cart data and operations.
- **payments**: Handles payment processing and related operations.

## Services

### 1. Gateway (`gateway`)

- **Port**: 4000
- **Framework**: Apollo Gateway
- **Description**: This service acts as the API gateway. It uses `IntrospectAndCompose` to get the schemas from the `users`, `auth`, `products`, `cart`, and `payments` services and exposes a single GraphQL endpoint. It also forwards the JWT from the client to the subgraphs.
- **Subgraph URLs**:
  - `users`: https://api-gembiz.adityabansal.in/users/graphql
  - `auth`: https://api-gembiz.adityabansal.in/auth/graphql
  - `products`: https://api-gembiz.adityabansal.in/products/graphql
  - `cart`: https://api-gembiz.adityabansal.in/cart/graphql
  - `payments`: https://api-gembiz.adityabansal.in/payments/graphql

### 2. Users Service (`users`)

- **Port**: 4001
- **Framework**: Apollo Server (as a subgraph)
- **Database**: Supabase (assumed from `@supabase/supabase-js` dependency and `db` imports)
- **Description**: This service is responsible for all user-related operations.

#### GraphQL Schema

**Types**

```graphql
type User {
    id: ID!
    email: String!
    name: String
    phone: String
}
```

**Inputs**

```graphql
input userInput {
    email: String!
    password: String!
    name: String!
    phone: String
}
```

**Queries**

- `getUser(id: ID!): User`: Fetches a user by their ID.

**Mutations**

- `createUser(input: userInput!): User!`: Creates a new user. It checks if a user with the same email or phone number already exists. It creates an auth user in Supabase and then adds the user details to the `users` table.
- `upgradeToSeller(input: String!): User!`: Upgrades a user's role to "seller".

### 3. Auth Service (`auth`)

- **Port**: 4002
- **Framework**: Apollo Server (as a subgraph)
- **Database**: Supabase (assumed from `@supabase/supabase-js` dependency and `db` imports)
- **Description**: This service handles user authentication and generates JWTs upon successful login.
#### GraphQL Schema

**Types**

```graphql
type Auth {
    id: ID!
    email: String!
    name: String
    phone: String
    role: String
    token: String!
}

type ChangePasswordResponse {
    message: String!
    access_token: String!
    refresh_token: String!
}
```

**Inputs**

```graphql
input authInput {
    email: String!
    password: String!
}
```

**Mutations**

- `validateUser(input: authInput!): Auth`: Validates a user's credentials (email and password) using Supabase Auth. If successful, it returns user data along with a JWT.
- `changePassword(email: String!, currentPassword: String!, newPassword: String!): ChangePasswordResponse`: Changes a user's password after verifying the current password.

### 4. Products Service (`products`)

- **Port**: 4003
- **Framework**: Apollo Server (as a subgraph)
- **Database**: Supabase (assumed from `@supabase/supabase-js` dependency and `db` imports)
- **Description**: This service is responsible for all product-related operations. It includes authorization middleware to ensure only sellers can create, update, or delete products, and that users can only modify their own products. It verifies JWTs from the gateway to get user information.

#### GraphQL Schema

**Types**

```graphql
type Product @key(fields: "id") {
  id: ID!
  name: String!
  description: String!
  price: Float!
  seller: User
}

extend type User @key(fields: "id") {
  id: ID! @external
  products: [Product]
}
```

**Inputs**

```graphql
input ProductInput {
  name: String!
  description: String!
  price: Float!
}

input UpdateProductInput {
  name: String
  description: String
  price: Float
}
```

**Queries**

- `getProduct(id: ID!): Product`: Fetches a product by its ID.

- `getProducts: [Product]`: Fetches all products.

**Mutations**

- `createProduct(input: ProductInput!): Product`: Creates a new product, with the seller ID taken from the authenticated user's context.
- `updateProduct(id: ID!, input: UpdateProductInput!): Product`: Updates a product. Only the owner can update their product.
- `deleteProduct(id: ID!): Product`: Deletes a product. Only the owner can delete their product.

### 5. Cart Service (`cart`)

- **Port**: 4004
- **Framework**: Apollo Server (as a subgraph)
- **Database**: Supabase (assumed from `@supabase/supabase-js` dependency and `db` imports)
- **Description**: This service manages shopping cart operations, allowing users to add, remove, and view items in their cart.

#### GraphQL Schema

**Types**

```graphql
type Cart @key(fields: "id") {
  id: ID!
  user: User
  userId: ID!
  items: [CartItem!]
}

type CartItem {
  id: ID!
  cart: Cart
  cartId: ID!
  product: Product!
  productId: ID!
  quantity: Int!
}

extend type User @key(fields: "id") {
  id: ID! @external
  cart: Cart
}

extend type Product @key(fields: "id") {
  id: ID! @external
}
```

**Inputs**

```graphql
input CartItemInput {
  productId: ID!
  quantity: Int!
}
```

**Queries**

- `getCart: Cart`: Fetches the authenticated user's shopping cart.

**Mutations**

- `addItemToCart(item: CartItemInput!): Cart`: Adds an item to the authenticated user's cart.
- `updateCartItem(productId: ID!, quantity: Int!): Cart`: Updates the quantity of an item in the authenticated user's cart.
- `removeCartItem(productId: ID!): Cart`: Removes an item from the authenticated user's cart.
- `clearCart: Cart`: Clears all items from the authenticated user's cart.

### 6. Payments Service (`payments`)

- **Port**: 4005
- **Framework**: Apollo Server (as a subgraph)
- **Description**: This service handles payment processing, including creating payment orders and checking their status. It integrates with a payment gateway like Cashfree.

#### GraphQL Schema

**Types**

```graphql
type PaymentOrder {
  orderId: String!
  paymentSessionId: String!
  orderStatus: String!
}
```

**Inputs**

```graphql
input PaymentInput {
  productId: ID!
  amount: Float!
}
```

**Queries**

- `getPaymentStatus(orderId: String!): PaymentOrder`: Fetches the status of a payment order.

**Mutations**

- `createPaymentOrder(input: PaymentInput!): PaymentOrder`: Initiates a new payment order for a given product and amount. The user ID is derived from the authentication token.

## How to Run

The root `package.json` provides a convenient script to run all services concurrently:

```bash
npm run dev
```

This command will start the `gateway`, `users`, `auth`, `products`, `cart`, and `payments` services.
